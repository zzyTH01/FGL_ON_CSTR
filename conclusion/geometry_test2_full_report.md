# Mackey-Glass Geometry Test 2 — Full Report

## 实验目的

固定 τ=13（MG 方程的倍周期分岔甜品区），扫描 L+H-1 远离或接近 τ=13，检验**几何对齐程度（L+H-1 ≈ τ）对 FGL Δ 幅度是否有独立贡献**。

这是第一轮几何检验的互补实验：第一轮检验"峰值位置是否随配置移动"（位置维度），这一轮检验"对齐点的 Δ 是否显著更高"（幅度维度）。

**Run date:** 2026-07-05 21:18  
**τ:** 13 (fixed)  
**MG equation params:** β=0.2, γ=0.1, n=10, dt=1.0  
**Lyapunov:** +0.000953 | **Periodicity:** 0.9934  
**Seeds:** 0, 1, 2, 3, 4  
**Epochs per run:** 50  
**Total runs:** 35 (7 configs × 5 seeds)

## 判定

### 判定标准回顾

| 情形 | 判定条件 |
|------|------|
| ① 几何对齐独立贡献 | distance=0 处 Δ 显著更高（误差棒与 distance=±8 不重叠，比值 > 2×） |
| ② 动力学主导（平坦曲线） | 各 distance 下 Δ 均值在误差棒范围内接近，distance=0 无显著优势 |
| ③ 其他未建模变量 | 曲线非单调，不符合 ① 也不符合 ② |

### 关键数值对比

| 指标 | 值 |
|------|:---:|
| distance=0 (对齐点) | Δ = **+32.1% ± 20.2%** |
| distance=−8 (L=3,H=3) | Δ = **+21.0% ± 30.8%** |
| distance=+8 (L=11,H=11) | Δ = **+14.3% ± 8.9%** |
| d0 与 d−8 误差棒是否重叠 | **是**（d0: [11.9, 52.3], d−8: [−9.8, 51.8]，大幅重叠） |
| d0 与 d+8 误差棒是否重叠 | **是**（d0: [11.9, 52.3], d+8: [5.4, 23.2]，重叠） |
| d0 / avg(d±8) | **1.82×**（不满足显著差异的 2× 标准） |

### 最终判定：② 动力学主导（FLAT CURVE）

**FGL Δ 在 distance=0 处并非显著高于 distance=±8 处。误差棒大幅重叠，无法拒绝"曲线平坦"的零假设。**

### 关键证据

1. **L=3,H=3（dist=−8, 离对齐点最远）给出了 +21.0% 的正向 Δ**。如果几何对齐对 Δ 幅度有独立贡献，这个极端不对齐的配置应该接近零或为负。实际结果是正向的——因为 τ=13 的动力学甜品位才是决定因素。

2. **对齐点（dist=0）确实均值最高（+32.1%），但方差也很大（±20.2%）**。单看均值似乎支持几何效应，但统计检验不支持——与 distance=±8 的误差棒重叠度太高。

3. **L=11,H=11（dist=+8）给出了最稳定的正向 Δ：+14.3% ± 8.9%**——5 个种子全部正向。这个配置离对齐点有 8 个单位，但 FGL 效果比许多更接近对齐点的配置更稳定。

### 结论

**一旦 τ 进入 MG 方程的倍周期分岔甜品区（τ=13），FGL Δ 的幅度主要由 τ 的动力学状态决定。几何对齐（L+H-1 ≈ τ）对 Δ 幅度没有统计显著的独立贡献。**

结合第一轮几何检验（"峰值位置不移"）和第二轮（"峰值高度不随对齐变化"），两轮实验共同确证：**MG τ=13 甜品区是 MG 方程自身的动力学分岔结构的产物，与超参数 L、H 的选择无关——即稳健地排除了"纯 L+H−1 几何共振"这一竞争假说。** 需注意：此处证伪的是"几何共振假说"，并未单独证实"反馈环复杂度决定 FGL 效果"这一上游假说（见 [`final_conclusions.md`](final_conclusions.md) §3）。
