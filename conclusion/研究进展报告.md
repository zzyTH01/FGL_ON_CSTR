## 2. 既有核心结论(2026-07 前,已定论)

### 2.1 L 与 H 决定 FGL 落在有效区还是失效区
- CSTR L×H 25 配置 FGL Δ% 跨度约 **220 个百分点**(+11.6% → −209.0%);同 (L,H) 内 α×T 网格仅变动 10~15pp。
- CSTR 早期沿 7 个方向排查"是否实现问题"全部失败,正因它们改的全是 L,H 之外的非决定性变量(且卡在 L=8 死区)。

### 2.2 MG 阈值效应:`L + (H−1) ≥ τ`
- 固定 τ=13、H=5 扫 L:L=9→10 处 Baseline MSE 暴跌 **8.5×**(5.90→0.69)、FGL Δ% **+78.5% → −15.7%** 符号反转。临界位置与 `L+(H−1)=τ` 精确吻合,而非简单 L=τ。
- **适用边界**:公式仅在**固定 H 扫 L** 时严格成立。H 扫描耦合了 Teacher offset(=H−1),"任务难度"与"信息窗口"两效应竞争,呈非单调 U 型(Welch t:H<9 vs H≥9,p<0.01,复算 p≈0.005)。
- 几何检验排除了"纯 L+H−1 共振"假说:大幅改变几何后 τ_peak 始终落 [12,15],FGL 甜品区与系统动力学(倍周期分岔)绑定。

### 2.3 CSTR 地板效应(≈14.1)
- 当 L+H−1 足够大、周期信号可被历史窗口近乎完美外推时,Baseline 降至 ≈14.1 的 50-bin 离散化噪声地板;此时教师 1 步目标与学生 H 步目标错位,蒸馏有害甚至灾难性负向(−209%)。

### 2.4 直接机制:Teacher–Student 信息不对称
- 教师 `offset=H−1` 的窗口"看到"紧贴目标前的 H−1 步近未来。当联合窗口 L+H−1 小于系统记忆尺度 τ 时,这段近未来含学生推不出的新信息 → 蒸馏有效;否则教师信息不再独占 → 蒸馏退化为噪声。**阈值效应与地板效应是该机制的两个侧面**。
- Baseline MSE 与 FGL Δ% 的相关性**分系统**(L×H 扫描,25 格 cell 均值):**CSTR r=+0.49、MG r=+0.72**——这两个系统"任务越难,FGL 越有利";**Lorenz r=−0.88,方向相反**(增益集中在短 H=5 低难度区)。旧"三系统均正相关"表述不成立,已限定为 CSTR/MG。(2026-08-06 修订:CSTR 原 r=0.713、MG τ 扫描原 r=+0.451 均无法从当前数据复现,已替换为 L×H 扫描可复算值)

## 3. 2026-07 新进展

### 3.1 延迟反馈 CSTR 混沌化(工具链完成)

- 原生成器崩溃 → 修复为**有界控制 + 缓启动 + EMA 低通滤波**(`cstr/generate_delayed_stable.py`,有 14 个单元测试)。
- 正反馈(s=+1, A=0.9, β=0.03)下 **τ 分岔过渡曲线被复现**:τ 增大 → 周期 → 准周期 → 非周期。13 个数据集存于 `cstr/data/`。
- **Lyapunov 全正**:Rosenstein 最大 Lyapunov 指数 λ∈[0.0018, 0.0108]/样本,全部 13 数据集为正 → **真混沌,非噪声**(消除了此前"低周期性≠严格混沌"的 caveat)。
- λ 与 periodicity **不单调**(τ=30 λ 最大但 per=0.79 最高)→ "周期性"与"混沌度"是**两个独立维度**,不应混用。

### 3.2 混沌 CSTR 上的 FGL:一次性 FGL 无增益,连续蒸馏部分增益

- **一次性 FGL** 在混沌化 CSTR 上无干净增益(aperiodicity 提升不带来 FGL 增益,非单调)。
- **自适应连续蒸馏(E-iter)** 在延迟数据集上可再降 student MSE(+10~63%),但"E_iter ≈ A_iter"——**蒸馏超参数(权重方案)不决定地板**。
- 结论收敛为:**CSTR 对 FGL 普遍困难**,与地板战役互相印证。

### 3.3 地板成因战役(τ=100 深挖 L×H,13 cells × 3 seeds)—— 核心新结论

每 cell 记录 {baseline, baseline_converged, teacher, fgl_student, A_iter, E_iter} 六量,四假设判决:

| 假设 | 判决 | 要点 |
|---|---|---|
| **H1**: MG 式 `L+H−1≥τ` 相变普适 | **证伪** | CSTR 上 baseline 随 L+H−1 平缓下降(172→134),**无悬崖**。MG 的相变是几何特异性巧合,不普适到混沌 CSTR |
| **H2**: 连续蒸馏地板固定比例 | **支持(仅 τ=100)** | `c = E_iter/baseline ≈ 0.76`(CV=0.21,跨 L×H 网格恒定)——**只实测于 τ=100 混沌延迟 CSTR 单一数据集**;同族 τ50/τ150 单锚点 0.80/0.81 方向一致;原始周期1 CSTR 单点 ≈0.98、MG 无意义,未跨出延迟 CSTR 家族验证 |
| **H3**: 地板 ↔ teacher 数学关系 | **修正成立** | 裸拟合 R²=0.12 是假象(H 主导);固定 H 下 R²=0.47–0.73;**多元** `log(floor) = 3.83 + 0.016·teacher + 0.035·H − 3.49·(1/L)`,**R²=0.72**。H 系数 ≈ 4.4× Lyapunov λ → 严格 `exp(λH)` 形式证伪、定性成立 |
| **H4**: 蒸馏压破数据地板 | **regime-dependent** | E_iter vs 训到收敛 baseline:H=5 **+3.0**(1/9 赢,蒸馏有害)、H=15 **−20.7**(18/21 赢)、H=30 −10.2(6/9)。整体配对 t p=0.0002 |

**H4 的干净自检**:若蒸馏的赢只是"多训了几轮",应处处赢;实际**只在难 H 赢、易 H 输**——正是"教师信息在起作用、而非堆算力"的指纹,印证信息不对称机制。

**如何达到最低 MSE(可操作,三层洋葱):**
1. **数据难度(决定 ~72%)**:主降 H、提 L(L≈50 饱和)。应用约束决定,改不了多少。
2. **把模型训够**:baseline 从 30 轮训到收敛(100 轮)再降一截,触数据地板即止。
3. **按难度决定是否蒸馏**:H≥15 → 上连续蒸馏(再压 13–21%);H≈5 → 别蒸馏(反而 +3% 且费算力)。
4. **超参数不决定地板**(α/温度/加权):决定地板的是 **(L,H) + 数据可预测性 + "蒸不蒸馏"这个二分**。

> **适用范围声明(2026-08-06 修订):** H2 的 `c≈0.76` **仅实测于 τ=100 混沌延迟 CSTR 一个数据集**(13 cells×3 seeds);同族 τ50/τ150 单锚点(L20H15)为 0.80/0.81,方向一致。**未在原始周期1 CSTR(可比单点 ≈0.98)或 MG(E 干涸无意义)上成立。** 本小节"76 折券"与操作结论暂限延迟混沌 CSTR 家族,跨数据集外推需方案 C 去混杂横向实验(§5.1)。

### 3.4 自适应蒸馏变体 E 与 E-iter 框架化

- **变体 E 结论修订(2026-07-24)**:早期"自适应蒸馏未显著(p=0.42)"源于三重实现缺陷(标准错用 + 索引错位 + 温和加权)。修正为 teacher−student 逐样本 MSE 差距 + 零地板放大([0,4])后:**5×5 网格 47/50 cell×seed 优于 uniform 对照(94%),平均降 ~30%,配对 t=−8.16(p≪0.001)**(数据 `adaptive_lh_sweep.csv`,2 seeds,已审计);**锚点 L20H15 的 n=5 运行(原记 Δinit=+33.2%、p≈0.018)原始数据未存档,标注为网格级已验证、锚点待补档**。温和变体 C 仍处噪声边缘(+10.6%)——显著化主要来自放大版 E。
- **E-soft(稍软化)**:sigmoid 软地板(w_floor 可调)修复了 MG 上 E 的"干涸崩溃"(易任务权重全为零),但稀释 CSTR 的浓度优势。**w_floor 是浓度/稳定旋钮,无免费午餐**;静态地板无法兼得,动态地板(早期硬、后期软)是具体可验证的下一步 idea。
- **E-iter 纳入 FGL 框架(2026-07-31)**:`run_iterative_distillation` 重构为**双权重分布 × 单/迭代臂**——一次调用同时训练硬(E)与稍软化(E-soft),6 臂(A_single/A_iter 对照 + E/E-soft × single/iter);`cstr/run.py` 的 `iterative_distill` 实验默认启用,CLI `--distill_variants`/`--w_floor` 可切换,CSV 落盘;MG 保持关闭(负结果)。26 个测试全绿。

## 5. 下一步计划(按优先级)

1. **方案 C(去混杂)**:固定 periodicity 变 τ 的横向实验——把 H1 从"趋势"变**因果检验**,并把 H4 的 regime 结论推广到横向数据集。**(最高优先)**
2. **关键 cell 补种子**:n=3 的部分格子(H=30、H=5)偏噪,补到 5 seeds(接口已留)。
3. **独立 holdout**:当前 val≈test 偏乐观(keep-best-by-val 近似在 test 选优),H4 配对 t 需复核。
4. **变体 E 移植 MG/Lorenz**:验证 E/E-soft 的普适性;调 W_MAX/地板。
5. **动态地板**(E-soft 扫描的自然延伸):早期硬地板保浓度、后期软地板防干涸。
6. 量化信息不对称指标(互信息差/条件熵差)。
