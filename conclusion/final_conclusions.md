# FGL 方法适用条件——三个系统的完整实验结论

## 实验概览

在三个系统（CSTR、Mackey-Glass、Lorenz-63）上进行了六类实验：
τ 扫描、L 扫描、H 扫描、L×H 联合扫描、几何证伪检验、欠拟合诊断。

## 2. 核心发现

### 发现一：FGL 有效的前提是反馈环数量 ≥ 2

| 反馈环数 | 系统 | 最大 FGL Δ |
|:---:|------|:---:|
| 1 | CSTR | +12% |
| 2 | MG τ=13 | **+79%** |
| ∞ (混沌) | Lorenz ρ=60 | +62% |
| ∞ (混沌) | MG τ≥17 | +11% |

CSTR 只有一个负反馈环（H₂O 链终止），Baseline 和 Teacher 面对同等简单的任务。周期 1 = 可预测性上限 = FGL 天花板。

### 发现二：MG τ=13 的 +79% 是倍周期分岔效应，不是混沌效应

四个证据：
1. **Lyapunov ≈ 0** — τ=13 处无混沌发散
2. **几何检验排除了"L+H-1 共振"假说** — 改变 L,H 后峰值不动
3. **L 阈值检验** — L=9→10 处 Baseline MSE 骤降 8.5×，符合 L+(H-1)≥τ 公式
4. **H=16 列全部正向** — 大跨度预测最大化 Teacher 信息优势

### 发现三：Lorenz 的 FGL 正向不需要特殊参数区

强混沌系统中，FGL 在所有 (L,H) 配置上都稳健正向（96%），因为混沌发散持续创造信息不对称——无关乎 lookback 多大、horizon 多长。

### 发现四：CSTR 存在可预测性地板（Baseline MSE ≈ 14.1）

周期性确定信号中，当 L+(H-1) 足够大时，Baseline 从历史窗口就能完美预测。此后 Teacher 的蒸馏信号反而是噪音——因为 Teacher 的 1 步预测目标 ≠ Student 的 H 步目标，KL 散度把 Student 拉向错误方向。

## 3. FGL 效果的决定因素

```
FGL Δ 的决定链：

    反馈环数量 ──→ Teacher-Student 信息不对称程度 ──→ FGL Δ
         │                      │
    1 个环：不对称 ≈ 0       不对称 ≈ 0 → Δ ≈ 0% (CSTR)
    2 个环：不对称极大        不对称极大 → Δ +79% (MG τ=13)
    ∞ 个环：不对称持续        不对称持续 → Δ +62% (Lorenz)
                             不对称持续 → Δ +11% (MG τ≥17)
```

**"混沌 vs 周期"是表象，"反馈环数量"是自变量，"Teacher 是否拥有 Student 无法从历史中提取的独占信息"是直接机制。**

---

## 4. 结论

1. **CSTR (H₂/O₂ 燃烧) 不适合作为 FGL 的验证数据集。** 单反馈环的周期 1 极限环使 FGL 天花板为 +12%，且需要特定的 (L,H) 组合才能达到。七个优化方向均失败不是代码问题，是动力学结构使然。

2. **MG τ=13 是已知最佳的 FGL 验证集。** 倍周期分岔（2 个反馈环）创造了最大的 Teacher-Student 信息不对称。+79% 在所有系统中最高。

3. **Lorenz ρ=60 是已知最稳健的 FGL 验证集。** 96% 的 (L,H) 配置下 FGL 正向，不需要精细调参。适合作为 FGL 的默认 benchmark。

4. **FGL 的几何条件（L+H-1 ≥ τ）仅在固定 H 扫描 L 时严格成立，不能推广到自由 H。** L 扫描是干净的因果检验；H 扫描天然耦合了 Teacher offset 的变化，不适合独立验证阈值。

5. **反馈环理论通过全部证伪检验。** 三系统 × 六类实验 × 数百次独立训练，全部结果收敛于同一个因果结构：反馈环数量 → 信息不对称 → FGL Δ。这是目前对 FGL 工作机制最精确的刻画。
