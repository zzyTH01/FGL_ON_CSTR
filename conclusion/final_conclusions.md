# FGL 方法适用条件——三个系统的完整实验结论

> **口径说明（2026-07 更新）**：本文档早期版本曾把"**反馈环数量决定 FGL 效果**"作为确定性因果结论。经复核，该说法只能说明**相关性**——三系统的 FGL Δ 排序与反馈环数量一致，但缺乏严格的因果干预实验，且"可预测性差异""Teacher-Student 信息不对称程度"等替代解释同样自洽（三系统的 Baseline MSE ↔ FGL Δ% 均呈正相关即为一致证据）。故现将其**降级为探索性假说**，仅作为参考方向之一。

> - **(A) 稳健结论**（可重复）：L/H 的决定性作用、阈值效应、Baseline 地板效应、Teacher-Student 信息不对称这一直接机制。
> - **(B) 探索性假说**（非因果）：用"反馈环数量 / 倍周期分岔"来解释三系统差异。
>

>
> **自适应蒸馏结论更新（2026-07-24）**：本文档先前称"自适应逐样本蒸馏方向正确但未达统计显著（p=0.42、d=0.54）"。该结论基于**早期有缺陷的实现**：判定标准用 `max(0, CE_baseline − CE_teacher)`（baseline-CE 差），且逐样本误差的 teacher/student 索引存在**错位**（teacher loader 因 `offset=H−1` 使约 91% 的比较落在错误目标上），权重归一化也过温和（[0.2, 2.0]）。修正为 **teacher−student 逐样本 MSE 差距**（索引按 `j−(H−1)` 对齐）并采用**零地板放大版变体 E**（归一化到 [0, 4]；student 已做对的点蒸馏权重=0，全部预算集中在弱点）后，CSTR 上结果反转：L=20,H=15 达 Δinit=+33.2%（n=5，配对 p≈0.018），5×5 L×H 网格 **47/50** 个 cell×seed 上 E 优于 A，平均 student MSE 下降 30.4%（详见 [`best_sample_cstr.md`](best_sample_cstr.md) §五更新、`cstr/results/adaptive_lh_sweep.csv`）。**两点限定**：(1) 温和变体 C 即使修正后仍处噪声边缘（Δinit=+10.6%，n=5），显著化主要来自放大版 E；(2) 仅 CSTR 验证，MG/Lorenz 未做。故旧表述"蒸馏策略本身难以突破天花板"应限定为"温和加权下成立"。

## 2. 稳健结论（可重复）

### 2.1 L 与 H 是 FGL 是否有效的决定性变量

无论在哪个系统，(L, H) 配置都决定了 FGL 落在"有效区"还是"失效区"，其影响远超 α 与 T：

- **CSTR**：L×H 25 配置的 FGL Δ% 跨度约 **220 个百分点**（+11.6% → −209.0%）；而固定 (L,H) 后的 α×T 网格（6×6=36 组）仅变动约 10~15 pp。
- CSTR 早期沿 7 个方向排查"是否是实现层问题"之所以全部失败，正因它们改的全是 L、H 之外的非决定性变量（且固定在 L=8 死区），从未做跨越式的 L×H 联合扫描。

**判定**：L、H 决定有效区；α、T 仅在已选定有效区内精调。

### 2.2 阈值效应（MG）：`L + (H−1) > τ`

固定 τ=13、H=5 扫描 L 时，L=9→10 处两个量同时剧变：Baseline MSE 5.902→0.692（下降 8.5×），FGL Δ% +78.5%→−15.7%（符号反转）。临界条件为

$$L + (H-1) > \tau$$

代入 H=5、τ=13，临界点位于 L+H−1=13，即 L=9 与 L=10 之间，与实测吻合。L 与 Baseline MSE（r=−0.726）、L 与 FGL Δ%（r=−0.824）均强负相关。

**适用边界（重要）**：该公式**仅在固定 H 扫描 L 时严格成立**。H 扫描因同时改变 Teacher 的 offset、耦合了"任务难度"与"信息窗口"两个竞争效应，呈非单调 U 型，不能简单套用该阈值。

### 2.3 Baseline 地板效应（CSTR，≈14.1）

当 L+H−1 足够大、周期信号几乎可被历史窗口完美外推时，Baseline MSE 骤降至 ≈14.1 的**离散化噪声地板**（50-bin 量化下限），此时 FGL 转为负向甚至灾难性负向。

**机制**：Baseline 已能仅凭历史近乎完美预测目标；教师预测的是 `t+1`，学生需要的是 `t+H`，二者目标错位，KL 蒸馏把学生拉向错误方向。

### 2.4 直接机制：Teacher-Student 信息不对称

FGL 生效的直接机制是**信息不对称**：教师凭 `offset=H−1` 的时间偏移"看到"了紧贴目标之前的 H−1 步近未来——这正是学生无法仅凭历史窗口 L 获得的部分。当这段近未来携带"用历史无法推得"的新信息时（典型：联合窗口 L+H−1 小于系统内在记忆/延迟尺度 τ），蒸馏有效；一旦 L+H−1 足够大、学生历史已能覆盖相关依赖，教师"独占信息"不再独占，蒸馏退化为噪声。这是阈值效应与地板效应的共同根源。

> 三个系统均观测到 Baseline MSE 与 FGL Δ% 正相关（CSTR r=+0.713；MG τ 扫描 r=+0.451），即"任务越难、FGL 越有利"——与信息不对称机制自洽。

## 3. 探索性假说（非因果）：反馈环数量 / 倍周期分岔

> ⚠️ 本节内容是**待检验的假说**，不是确定性结论。

曾有一个颇具解释力的假说：FGL 的有效性由**系统中非线性反馈环的数量**决定——

| 反馈环数 † | 系统 | 最大 FGL Δ |
|:---:|------|:---:|
| 1 | CSTR | +12%（扫描内）/ +25.7%（精细网格） |
| 2 | MG τ=13 | +78.5% |
| ∞ | Lorenz ρ=60 | +62.2% |
| ∞ | MG τ≥17 | +11% |

支持该假说的观察：
1. MG τ=13 的峰值（+78.1%）出现在 **Lyapunov ≈ 0** 的倍周期分岔区，而非混沌区——"混沌"不是 FGL 生效的必要条件。
2. 几何检验排除了"纯 L+H−1 共振"假说：大幅改变 L+H−1（9→16）后，FGL 峰值位置 τ_peak 始终落在 [12, 15]，不随几何对齐而搬家（详见 [`geometry_test_full_report.md`](geometry_test_full_report.md)、[`geometry_test2_full_report.md`](geometry_test2_full_report.md)）。
3. Lorenz 强混沌下 FGL 几乎全配置正向（96%），无需精调。

**为何只作为假说**：
- 缺乏严格的因果干预实验（没有在"只改变反馈环数量、其余不变"的条件下做对照）；
- 替代解释同样自洽：三系统的差异完全可以由**可预测性差异**或**Teacher-Student 信息不对称程度**解释，不必诉诸反馈环计数；
- 反馈环数量本身难以严格定义与计数（尤其对 ODE 系统），且三系统样本数太少（n=3）。

因此，"反馈环数量 → 信息不对称 → FGL Δ"这条因果链宜表述为**一种可能的上游解释**，而非已证实的机制。直接、可操作的机制仍是 §2.4 的信息不对称。

## 4. 结论

### 4.1 主要结论

1. ✅ **FGL 在三个数据集上均有效，但强度与稳健性差异悬殊**
   - CSTR：L=20,H=12，5 种子 +25.7%（精细网格最佳；L×H 扫描内仅 +11.6%，需精扫才能找到）。
   - MG τ=13：L=9,H=5，+78.5%（强度最高）。
   - Lorenz ρ=60：L=8,H=5，+62.2%（96% 配置正向，最稳健）。

2. ✅ **L 与 H 是核心因素**：三系统上 (L,H) 配置均起决定作用；α、T 仅精调。CSTR 早期七方向优化全部失败，正因它们改的全是 L、H 之外的非决定性变量。

3. ✅ **阈值效应（MG）**：严格验证 `L+(H−1) > τ`（固定 H 扫 L 时成立）。

4. ✅ **Baseline 地板效应（CSTR）**：Baseline 过易（MSE 降至 ≈14.1 离散化噪声地板）时 FGL 失效甚至有害。

5. ✅ **直接机制是 Teacher-Student 信息不对称**：教师凭时间偏移获得学生无法从历史推得的近未来信息，是 FGL 有效的直接、可操作机制。

6. ⚠️ **"反馈环数量 / 倍周期分岔"为探索性假说，非因果结论**：三系统 Δ 排序与反馈环数量一致仅说明相关；蒸馏策略方面，早期"自适应逐样本蒸馏未达显著（p=0.42）"的结论经复核为**实现缺陷所致**（baseline-CE 标准 + 索引错位 + 温和加权），修正为 teacher−student MSE 差距（对齐）+ 零地板放大变体 E 后，CSTR 上达显著（p≈0.018）并网格级有效（见顶部 2026-07-24 更新）。

### 4.2 局限性

1. **系统覆盖有限**：仅 3 个系统、1 种主干架构（2 层 RNN，部分 LSTM 对照）。
2. **种子方差偏高**：部分配置变异系数 >1，关键结论应配合 ±std 或显著性检验。
3. **阈值公式适用边界**：`L+(H−1) > τ` 仅在固定 H 扫 L 时严格成立。
4. **"反馈环数量"假说为相关性而非因果**：未经因果干预证实，宜作待检验假说（详见 §3）。
5. **自适应蒸馏结论已修正**：早期"n=5、d=0.54、未达显著"是基于有缺陷实现（见顶部 2026-07-24 更新）的结果；修正后的变体 E 在 CSTR 显著（p≈0.018）且网格级有效（47/50 cell×seed，均值 −30.4%），但温和变体 C 仍处噪声边缘，且仅 CSTR 验证、MG/Lorenz 待做。

### 4.3 未来工作

1. 量化 Teacher-Student 信息不对称的指标（互信息差、条件熵差），使其可计算、可比较。
2. 改进教师/学生目标对齐，削弱 H 对教师 offset 的耦合。
3. 在更多动力学系统（Rössler、Duffing、BZ 反应等）上检验结论普适性，并对"反馈环"假说做因果干预检验。
4. ~~在更大种子数下复核自适应蒸馏能否突破当前天花板。~~ **(2026-07-24 部分完成)**：修正实现后变体 E 在 CSTR 已突破（显著、网格级有效）；待办：移植到 MG/Lorenz 验证普适性，并调 W_MAX/地板。
